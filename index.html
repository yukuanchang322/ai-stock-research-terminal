      研究方法

      研究流程固定為：定義問題 → 多來源蒐集 → Evidence 正規化 → 官方性/期間/新鮮度/衝突驗證 → Fact/Derived Fact/Estimate 分層 → 基本面/技術面/籌碼面 → 預期差 → 估值 → 結論/成立條件/失效條件 → PDF 固化。

      1. AI 不補缺失財務數字。
      2. 價格、MA20/MA60、KD、MACD、RSI、法人 1/5/20 日買賣超與估值由程式計算。
      3. 法人研究聚合公開網路標題、摘要與數值，保留原始來源連結，不重製付費全文。
      4. 每份 PDF 固定保存產生時間、資料日期與估值基礎。
