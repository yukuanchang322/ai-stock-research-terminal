# PDF font

`NotoSansTC-VF.ttf` is the Traditional Chinese Taiwan subset variable font
from the official Noto CJK project. It is used only by the ReportLab PDF
fallback so generated reports embed readable Traditional Chinese glyphs.

Source: https://github.com/notofonts/noto-cjk
